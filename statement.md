# Project Statement

## Project Title
Smart Study Planner & Performance Analyzer

## Problem Statement
Semester-1 students often have several subjects with different difficulty levels and limited study time. A simple terminal application can help organize subjects, create a priority-based study plan, record marks, and analyze academic performance.

## Scope
The project accepts subject information, difficulty, available weekly study hours, and marks. It generates a rule-based study priority list and provides a performance report. The project is intentionally limited to a terminal interface and simple Python algorithms suitable for the CSE1021 syllabus.

## Target Users
- Engineering students
- Students preparing for internal examinations
- Beginners learning programming and algorithmic problem solving

## High-Level Features
1. Create/update a study plan.
2. Assign priority to subjects using a simple algorithm.
3. Record subject marks.
4. Calculate total and average marks.
5. Assign grades.
6. Identify the most difficult and lowest-scoring subjects.
7. Save and reload data using a JSON file.
