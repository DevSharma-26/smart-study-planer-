# Smart Study Planner & Performance Analyzer

## Overview

Smart Study Planner is a simple terminal-based Python project made for CSE1021 - Introduction to Problem Solving and Programming.

The program helps a student:
- create a study plan
- give each subject a difficulty level and weekly study hours
- arrange subjects by priority
- enter marks
- calculate total, average and grade
- find simple performance information
- save the information in a JSON file

## Project style

This version keeps all Python code in **one file: `main.py`**. This makes the project easier to understand and run as a beginner Python project.

## Files

- `main.py` - complete Python program
- `statement.md` - problem statement and project scope
- `Smart_Study_Planner_Project_Report.pdf` - project report

## How to run

1. Install Python 3.10 or newer.
2. Open a terminal inside the `SmartStudyPlanner` folder.
3. Run:

```text
python main.py
```

No external package is required to run the main program.

## Testing
The main program can be tested by running it and trying different inputs, including invalid numbers. The important calculations are kept as simple functions inside `main.py`, so they can also be checked manually.
